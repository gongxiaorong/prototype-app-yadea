### 关键修复：`curStore` 被共享内核覆盖

`authState` 的返回对象里已有 `curStore`（用户端地图选中门店，`Vue.ref('')`）。原写法 `Object.assign({ 业务键… }, auth, sideSetup(...))` 中 auth 在业务键之后，导致门店详情的 `curStore` computed 恒被覆盖为空串 → 页面永远显示「门店不存在」。现改为：

```js
return Object.assign({},auth,sideSetup('换电商户端',toastBus),{ /* 业务键 */ })
```

即共享内核铺底、业务键最后覆盖（`curStation/curCab/curBatt` 与 auth 无冲突）。

## 关键约定（务必遵守）

- 组件标签 kebab-case 且显式闭合；`open` prop 只声明 `{default:false}`；自定义指令必须传函数
- 二级页用 `<page>` 壳 + `<nav-bar>` 头（标题居中三规则）；底部弹窗只用 `bottom-sheet` / `option-sheet` / `confirm-dialog`；空态用 `empty-state`
- 页面打开顺序：先 `navOpen()` 再改状态；返回用 `navBack()`
- 数据类 ref 不得注册进导航快照（避免返回回滚）
- 状态色标：绿 `#16A34A` / 红 `#DC2626` / 橙 `#FF8A00` / 灰 `#999999`
- 门店↔站点为 1:1，单一真相是 `store.stationId`，站点侧所属门店由门店反查（`storeOfStation`）
